B. Control Bidireccional de Servos via NFC (Arduino Uno <-> App):
   1. Mapa de Memoria NTAG213:
      - Paginas 4 a 7:  Slot A Ping-Pong (Telemetria 12 bytes + marcador commit).
      - Paginas 8 a 11: Slot B Ping-Pong (Telemetria 12 bytes + marcador commit).
      - Pagina 12:      Canal de Comandos App -> Arduino.
                        Estructura (4 bytes): [0x53 ('S'), byte pitch (0-180), byte yaw (0-180), byte checksum]
                        Checksum: (0x53 + pitch + yaw) & 0xFF.

   2. Firmware Arduino Uno (ATmega328P):
      - Archivos: src/NfcTransceiver.cpp, include/NfcTransceiver.h, src/SolarTracker.cpp, include/SolarTracker.h, src/main.cpp.
      - Lee la pagina 12 con APDU READ (0x30, 12).
      - Valida byte magico y checksum.
      - Actualiza servomotores y escribe ceros en la pagina 12 para evitar re-ejecucion de comandos obsoletos.
      - Uso de Memoria: RAM 30.6% (627 bytes de 2048) / Flash 39.5% (12,754 bytes de 32,256).

   3. Aplicacion Movil (Flutter):
      - Archivos: heliostrand_app/lib/services/nfc_service.dart, heliostrand_app/lib/services/simulation_service.dart.
      - Encola comando con queueServoCommand(pitch, yaw) al mover sliders.
      - Transmite automaticamente via APDU WRITE (0xA2, 12, ...) al aproximar el tag.
      - Permite control manual reflejado en tiempo real en Modo Simulacion.
